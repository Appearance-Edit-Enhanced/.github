Appearance Edit Enhanced is a character customization mod for Baldur's Gate 3 that expands the game's appearance editing system. It allows players to change the race and body type of any character, access the Magic Mirror with Origin characters, and customize companions beyond the original game's restrictions.

## Overview

Appearance Edit Enhanced extends Baldur's Gate 3 character customization through additional in-game spells and expanded access to the character creation interface.

The mod supports custom characters, Origin characters, and other party members, providing more control over character appearance, race, and body configuration.

## Features

- **Race Editing** — change the race and subrace of supported characters.
- **Body Type Customization** — modify character body types beyond the standard appearance editing options.
- **Magic Mirror Access** — open the appearance editor for characters that normally cannot access it.
- **Origin Character Editing** — customize Origin characters using the optional Appearance Edit Origins file.
- **Resculpt Spell** — reopen the character creation interface to change race, subrace, body type, and appearance.
- **Respec Spell** — access a Withers-style respec without additional functionality.
- **Restore Spell** — restore an Origin character's original appearance and help resolve certain customization issues.

## Origin Character Support

Appearance Edit Enhanced includes support for editing Origin characters, with an additional optional file required to unlock their full appearance customization.

The separate Appearance Edit Origins file enables appearance editing for Origin characters through the Magic Mirror.

The Script Extender is required for character editing functionality. The author recommends using its latest version.

### Optional Component

- **Appearance Edit Origins** — required if you want to edit the appearance of Origin characters through the Magic Mirror. The main Appearance Edit Enhanced file must also be installed.

## Compatibility Notes

- The Nexus Mods page identifies version 3.1.3 as compatible with Baldur's Gate 3 Patch 8.
- Some appearance options may conflict with other mods that modify the same character customization files.
- Significant body-size changes can cause problems in the Magic Mirror, level-up, and respec interfaces.
- In multiplayer, casting Resculpt opens the character creation interface for every player in the lobby. Other players must follow the author's instructions to exit the interface safely.
- After changing race, save and reload to apply racial passives, spells, and background changes.
- Uninstalling after changing a character's race or body type can cause visual issues in the Mirror, Respec, and Level-Up interfaces. The author recommends using the Restore spell before removal.
